# Phase 0 — Requirements Engineering

This phase defines **what the system must do** and **under which constraints**.
All design decisions in later phases must trace back to the requirements defined here.

## Objectives
- Interpret competition rules into engineering language
- Define measurable and verifiable system requirements
- Identify system constraints (dimensions, weight, power, cost)
- Define interfaces between mechanical, electrical, and software subsystems

## Contents
- Competition rules interpretation
- Functional and non-functional requirements
- System constraints table
- Interface definitions
- Success metrics and acceptance criteria

## Deliverables
- Requirements specification document
- Traceability-ready requirement IDs
